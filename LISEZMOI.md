# Contenu en ligne ACADENA

Produit par `npm run contenu:publier` (ACADENA 0.52.0) le 2026-10-05 : ne pas modifier à la main.
Les modules viennent de `content/published/` dans le projet ; les voix, de `npm run voix:generer -- --en-ligne`.

- `index.json` : la liste des modules et des voix, lue par l'app ;
- `modules/<id>.json` : un module ;
- `voix/<compagnon>/<clé>.ogg` : la voix d'une phrase de ces modules.

- Calcul mental (ce2-calcul-mental, version 1.0.0, ce2)
